Project Overview
 Baby & Blossom is a website that provides information to visitors about doula services for expecting parents. The purpose for the website is for expecting parents to learn about the doula and the services that are provided to families seeking a doula. 

 How to use the website
 There are four pages that consists of home, about, services, and contact. The visitors can navigate the website using the navigation bar at the top of the website page. The home page introduces Baby & Blossom and provides an overview of available support. The about page provides information about the doula and her approach to supporting families. The services pages describes the doula services offered. The contact page allows for visitors to view and completd a contacqt form to request information. 

 Technologies Used
The technologies used were HTML, CSS, Bootstrap, and Git and github.
